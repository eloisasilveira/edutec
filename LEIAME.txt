SINAPSE.lab — projeto para VS Code
==================================

Arquivos:
  index.html      -> a página (estrutura)
  style.css       -> todo o CSS
  script.js       -> todo o JavaScript
  GLTFLoader.js   -> carregador do modelo 3D (biblioteca Three.js)
  brain-data.js   -> o modelo 3D do cérebro, já embutido como dados
  bg-inicio.jpg   -> imagem de fundo da página Início
  jogo.html       -> o jogo "Dentro da Mente" (aba do mesmo nome)

Como usar:
  1. Abra a pasta inteira no VS Code (File > Open Folder).
  2. Clique com o botão direito em index.html > "Open with Live Server"
     (extensão Live Server), ou só dê dois cliques no index.html
     para abrir no navegador.

Importante: mantenha os 8 arquivos na MESMA pasta — o index.html
procura todos os outros ao lado dele.

As fontes (Space Grotesk, Manrope, JetBrains Mono) e a biblioteca Three.js
vêm da internet (Google Fonts e cdnjs), então precisa de conexão para
carregar certinho — inclusive para a aba "Cérebro 3d".

Sobre o modelo 3D do cérebro: é um modelo anatômico real (não desenhado
à mão), licenciado como CC-BY-4.0 — autor "mwtb33" no Sketchfab, com base
num modelo do NIH 3D Print Exchange por Nevit Dilmen. Uso livre, só
precisa manter a atribuição caso o modelo seja reutilizado fora deste
projeto.

Sobre o jogo "Dentro da Mente": é um arquivo independente (jogo.html).
Ele abre dentro da aba do site, mas também funciona sozinho — basta dar
dois cliques nele. São 5 fases e 8 vidas, e não depende de internet.
